# Real-estate-market-analysis_
An Excel-based real estate market analysis project exploring property prices, sales trends, neighbourhood performance and housing quality.
### Housing Market Trends & Property Valuation | Ames Housing Dataset

## 1. Project Overview

This project focuses on analysing residential property sales in Ames, Iowa, United States, using the Ames Housing Dataset.

The dataset covers property sales between 2006 and 2010 and contains information about property characteristics, neighbourhoods, quality and sale prices.

The objective was to transform raw housing data into meaningful business insights by identifying property pricing patterns, analysing neighbourhood performance and exploring factors that influence residential property values.

The project was developed entirely in Microsoft Excel.

## 2. Business Problem

Understanding property market trends is important for making informed real estate and investment decisions.

However, raw property data can be difficult to interpret without proper organisation and analysis.

This project addresses the need to:
- Understand differences in property prices across neighbourhoods.
- Identify patterns in residential property sales.
- Examine how property characteristics relate to selling prices.
- Present market information in a clear and accessible format.

## 3. Project Objectives

- Analyse residential property sales and pricing trends.
- Compare average selling prices across neighbourhoods.
- Examine the relationship between property age and sale price.
- Investigate how property quality influences selling prices.
- Identify trends in housing market activity between 2006 and 2010.
- Develop an interactive dashboard to communicate findings.

The raw dataset was prepared for analysis through data organisation and cleaning.

The preparation process included:
- Reviewing missing values.
- Checking data consistency.
- Reviewing data types and formats.
- Preparing relevant variables for analysis.
- Creating calculated fields to support further analysis.

## 6. Key Performance Indicators (KPIs)

The dashboard tracks the following performance indicators:

- Total Properties Sold
- Average Sale Price
- Highest Sale Price
- Average House Age

These indicators provide a high-level overview of the residential property market.
